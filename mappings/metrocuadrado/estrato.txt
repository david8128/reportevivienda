REGEX PARA TEXTO:
------------------------------------------------------------------
  Patrón 1: [Ee]strato[:\s]+(\d)
  Patrón 2: \bestrato\s*([1-6])\b
  Patrón 3: [Ee]strato\s+(uno|dos|tres|cuatro|cinco|seis)

NORMALIZACIÓN TEXTO A NÚMERO:
  "uno" → 1, "dos" → 2, "tres" → 3
  "cuatro" → 4, "cinco" → 5, "seis" → 6

VALORES Y FILTROS:
------------------------------------------------------------------
  Estrato 1-4 → INCLUIR en resultados (cumple filtro preferido)
  Estrato 5-6 → EXCLUIR (no cumple filtro ≤ 4)
  Estrato 3   → ÓPTIMO para arriendo (+5 puntos extra)

DIFERENCIAS CON FINCARAIZ:
------------------------------------------------------------------
  - __NEXT_DATA__ puede devolver estrato como número directo (más confiable)
  - MetroCuadrado puede omitir el estrato para propiedades campestres

NOTAS:
------------------------------------------------------------------
- Si se extrae de descripción → "estimado - requiere confirmación"
- Si null → pendiente de confirmación
- Rango válido: 1-6
