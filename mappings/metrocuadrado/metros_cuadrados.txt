SELECTORES ESPECÍFICOS DE METROCUADRADO (estructura React):
------------------------------------------------------------------
  MetroCuadrado suele generar clases de CSS-in-JS como "sc-XXXX" o "css-XXXXX"
  Usar atributos data-* como alternativa más estable:
  
  [data-property="area"], [data-field="area"]
  
  También buscar en el estado inicial de React:
  window.__NEXT_DATA__ o window.__INITIAL_PROPS__
  Parsear JSON → buscar "area" o "metrosCuadrados"

------------------------------------------------------------------
EXTRACCIÓN DESDE WINDOW.__NEXT_DATA__ (método preferido):
------------------------------------------------------------------
  const nextData = JSON.parse(
    document.getElementById('__NEXT_DATA__').textContent
  );
  // Navegar el objeto hasta encontrar área:
  nextData.props.pageProps.property.area
  nextData.props.pageProps.listing.features.area
  nextData.props.pageProps.result.attributes.area_total

REGEX PARA EXTRACCIÓN DE TEXTO:
------------------------------------------------------------------
Patrón 1: (\d{1,4})\s*m²
Patrón 2: [Áa]rea[:\s]+(\d{1,4})\s*(?:m²|metros?)
Patrón 3: (\d{1,4})\s*metros\s*cuadrados?
Patrón 4: área\s*(?:construida|privada|total)?[:\s]+(\d{1,4})

------------------------------------------------------------------
DIFERENCIAS CON FINCARAIZ:
------------------------------------------------------------------
  - MetroCuadrado muestra frecuentemente "Área total" y "Área privada" por separado
  - Si hay ambas → guardar "Área privada" como campo principal
  - La estructura React puede cambiar los nombres de clases con cada deploy
  - Preferir extracción de __NEXT_DATA__ o __INITIAL_STATE__ sobre CSS
