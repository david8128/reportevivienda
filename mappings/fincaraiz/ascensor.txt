DESCRIPCIÓN DEL CAMPO:
  Indica si el edificio tiene ascensor/elevador.
  Valores: true (tiene ascensor) / false (no tiene)
  Muy relevante cuando el piso es > 2.

------------------------------------------------------------------
SELECTORES CSS PRIMARIOS (VERIFICADOS):
------------------------------------------------------------------
[1] .property-facilities .CO-facility-batch  (badges de amenidades/facilidades)
      → Cada amenidad es un badge independiente: "• <span>Nombre</span>"
      → "Ascensor" aparece como uno de los badges SI Y SOLO SI el edificio lo tiene
      → Si no está en la lista → no tiene ascensor (o no fue reportado)
[2] [class*="ascensor"], [class*="elevator"], [class*="lift"]  (fallback genérico, no confirmado)
[3] li:has(span:contains("Ascensor")) strong  (fallback genérico, no confirmado)

------------------------------------------------------------------
LÓGICA DE DECISIÓN ESPECIAL:
------------------------------------------------------------------
  - Si la propiedad es una CASA → ascensor = false (asumir, marcar como estimado)
  - Si el piso es 1 o 2 → ascensor puede ser false sin penalización
  - Si el piso es > 2 y no hay información de ascensor → "estimado - requiere confirmación"
  - Si el piso es > 5 y no hay ascensor → marcar como observación importante

------------------------------------------------------------------
NOTAS DE IMPLEMENTACIÓN:
------------------------------------------------------------------
- El ascensor suma +5 puntos en el sistema de puntuación
- Si el tipo es "casa independiente" → no buscar este campo (dejar false por defecto)
- Si aparece en lista de amenidades sin valor explícito → asumir que sí tiene (true, estimado)
- Si se extrae de descripción → campo = "estimado - requiere confirmación"
