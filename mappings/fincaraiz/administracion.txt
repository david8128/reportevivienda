REGEX PARA EXTRACCIÓN DE TEXTO:
------------------------------------------------------------------
CASO A - valor extraído desde la ficha técnica (selector [1]):
  El texto ya viene aislado como "$ 700.000" (sin la palabra "administración").
  Patrón: \$\s*([\d.,]+)

CASO B - valor extraído desde el badge de precio (selector [2]):
  El formato real es "+ $ 700.000 administración" → la etiqueta va DESPUÉS del número.
  Patrón: \+?\s*\$\s*([\d.,]+)\s*administraci[oó]n

Patrones genéricos de respaldo (label antes del valor, no confirmados en esta ficha):
  Patrón 3: [Aa]dministraci[oó]n[:\s]+\$?\s*([\d.,]+)
  Patrón 4: [Aa]dmin[:\s]+\$?\s*([\d.,]+)
  Patrón 5: \$\s*([\d.,]+)\s*(?:/|por)\s*mes  (en contexto de administración)
  Patrón 6: cuota[:\s]+\$?\s*([\d.,]+)

NORMALIZACIÓN:
  - Remover puntos de miles → número entero (ej. "700.000" → 700000)
  - Remover espacio entre "$" y el número (formato real usa "$ 700.000")
  - Si dice "incluida" o "incluye" → valor = 0 (está en el precio)
  - Si dice "no aplica" o "no tiene" → valor = 0
  - Si dice "N/A" o "--" → valor = null (desconocido)
  - Si termina en "mil" → multiplicar por 1.000

NOTAS DE IMPLEMENTACIÓN:
------------------------------------------------------------------
- Rango razonable: 0 - 2.000.000 COP/mes
- Si supera 2.000.000 → verificar (posible error de scraping)
- Casas independientes usualmente no tienen administración (valor 0)
- Distinguir administración de "cuota de parqueadero" o "cuota de piscina"
- Si aparece rango (ej. "250.000 - 350.000") → tomar el valor mayor (conservador)
- Si no se encuentra → campo = "no disponible" (no marcar como estimado)
